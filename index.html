About

Clean code, clear layouts, kind to every screen size.

I started with a simple question: why do some websites feel effortless while others seem hard to navigate? Since then I've been studying layout, typography and interaction and putting them to work in real projects.

I like starting on paper, moving to Figma, then building with plain HTML, CSS and JavaScript so I understand every line. I care about keyboard access, readable contrast and fast load times as much as the visual polish.
